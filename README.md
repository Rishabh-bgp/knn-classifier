# K-Nearest Neighbors (KNN) Classifier in Python with scikit-learn — Iris Dataset

A simple, beginner-friendly machine learning Jupyter notebook that trains a K-Nearest Neighbors classifier on the classic Iris dataset using scikit-learn.

Part of: [Machine Learning Tutorials For Beginners Using Python In Hindi](https://www.youtube.com/playlist?list=PLu0W_9lII9ai6fAMHp-acBmJONT7Y4BSG)

## What it does
- Loads the Iris dataset
- Prints a sample and the full dataset description
- Trains `KNeighborsClassifier`
- Predicts class labels for custom input measurements

## Requirements
- Python 3
- scikit-learn
- Jupyter Notebook or Google Colab

## How to run
1. Open `K_Nearest_Neighbour_Classifier.ipynb`
2. Run all cells from top to bottom

## Dataset
Iris plants dataset — 150 samples, 4 features, 3 classes:
- Iris-Setosa
- Iris-Versicolour
- Iris-Virginica

Features used:
- Sepal length (cm)
- Sepal width (cm)
- Petal length (cm)
- Petal width (cm)
